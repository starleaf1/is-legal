# Seed data

Fictional sample documents for the emulator demo, uploaded by
`npm --prefix functions run seed`. "Northland" is a made-up country and these
"laws" are invented: they deliberately don't describe any real jurisdiction.

- `acme/`: Acme Corp's knowledge base (code of conduct, policies, two
  Northland law excerpts, two declassified case records).
- `globex/`: a second tenant. Its gifts policy contains the phrase
  "Platinum Hospitality Allowance", which must never appear in an answer
  given to an Acme employee. It's a canary for tenant isolation.
